# Shihui Xue Academic Homepage

This is a static GitHub Pages homepage prepared in a style similar to the academic layout of `hisssec.github.io`, with original HTML/CSS and Shihui Xue's own content.

## Files to upload
Upload **all files in this folder** to the root of your GitHub Pages repository (`YOUR_USERNAME.github.io`).

- `index.html` — homepage
- `profile.jpg` — profile photo
- `paper_tcsvt.png` — publication teaser image
- `paper_icassp.png` — publication teaser image
- `paper_icic.png` — publication teaser image
- `Shihui_Xue_CV.pdf` — CV
- `Patent_Certificate.pdf` — patent certificate

## GitHub Pages
Repository → **Settings** → **Pages**

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

Then open `https://YOUR_USERNAME.github.io/`.

## Notes
GitHub / Google Scholar / ORCID / DBLP buttons are intentionally omitted because no links were provided. Add them later only when you have public profile URLs.
